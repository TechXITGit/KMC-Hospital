Add these image files here before running the app (Expo requires them):

- icon.png            (1024x1024) — App icon
- splash.png          (1242x2436 recommended) — Splash screen image
- adaptive-icon.png   (1024x1024) — Android adaptive icon foreground
- favicon.png         (48x48) — Web favicon

You can use the KMC Hospital logo for these. Until real assets are added,
you can generate quick placeholders at https://icon.kitchen or similar tools.
